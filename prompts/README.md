## 🔧 نکات مهم

### 1. هر فاز در چت جدید
**چرا؟**
- Context window محدود است
- هر فاز مستقل است
- از تداخل جلوگیری می‌شود

### 2. تست پس از هر فاز
**چرا؟**
- مشکلات زود شناسایی می‌شوند
- از انباشت خطاها جلوگیری می‌شود
- اطمینان از صحت پیاده‌سازی

### 3. استفاده از contract.md
فایل `contract.md` در ریشه پروژه شامل قرارداد کامل API است. این فایل را می‌توانید به AI بدهید تا دقیقاً مطابق قرارداد پیاده‌سازی کند.

### 4. سازگاری با فرانت‌اند
تمام پرامپت‌ها بر اساس فرانت‌اند موجود طراحی شده‌اند. Response format باید دقیقاً مطابق فرانت‌اند باشد:

```json
{
  "success": true,
  "data": { ... },
  "message": "optional"
}
```

### 5. Error Handling
تمام خطاها باید این فرمت را داشته باشند:

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "پیام خطا به فارسی",
    "details": null
  }
}
```

## 🐛 رفع مشکلات رایج

### مشکل: پروژه build نمی‌شود
**راه‌حل:**
```bash
./mvnw clean install -DskipTests
```

### مشکل: Database connection error
**راه‌حل:**
- PostgreSQL در حال اجرا است؟
- Database `ai_platform` ایجاد شده؟
- Username/password صحیح است؟

### مشکل: Redis connection error
**راه‌حل:**
- Redis در حال اجرا است؟
- Port 6379 باز است؟

### مشکل: CORS error در فرانت‌اند
**راه‌حل:**
- CorsConfig پیاده‌سازی شده؟
- Origin صحیح تنظیم شده؟

### مشکل: API response format mismatch
**راه‌حل:**
- ApiResponse class درست پیاده‌سازی شده؟
- Controller ها از ApiResponse استفاده می‌کنند؟
